## One Source-To-Pixel Route

| Edge and owner | Exact proof product and rejection |
| --- | --- |
| Publisher -> Showcase content | Original archive/file hashes, rights/notices, parent packs and source inventory. A license string or download receipt alone is insufficient. |
| Conversion/import -> SourceImporters/Cooking | Geometry/count/bounds, units/handedness/winding, transforms, UVs, texture/color spaces and material/light/camera loss report before/after conversion. Unknown or silently dropped required semantics blocks the claim. |
| Cook/Assets -> World/Scene/View | Deterministic dependency closure, relative paths, active level, pose/camera/settings and immutable contributing generations. A failed requested map cannot pass by showing Empty. |
| Scene/shader/ABI -> Renderer/RHI | One material/pixel trace through actual source/options/cook/binding/native event and output domain on both APIs. A plausible beauty image or generic preview is not material fidelity. |
| Raw Reference -> comparison | Accepted estimator/transport domain, committed prefix and uncertainty, analytic/minimal/independent controls and exact scene/camera population. No denoised/display image or shared unchecked tracer approves itself. |

This sequence does not require the later neural diffuse-component output; M2 qualifies raw scene/reference truth and NG-S1 separately qualifies its component after M3. Preserve accepted Reference mathematics and scope.
