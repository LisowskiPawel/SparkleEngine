# PTLAS Supported Delivery Plan

[Docs](../../../../../../../README.md) / [Up](PtlasDesign.md)

**Status:** selected target sequence; discovery and prerequisite gates remain open. No stage is executed by this plan.
**Contract:** [design, semantics, measurement and local acceptance](PtlasDesign.md); [Roadmap](../../../../../../../Strategy/Roadmap.md) owns global order.

## Work This Plan

Production follows REL-11 and correct prepared-scene/BLAS/TLAS/SBT proof. Existing experimental code must earn the supported subset; PTLAS is now a selected portfolio feature, not an optional undocumented toggle. Execute the first unfinished stage only. The discovery card freezes numerical tolerances, practical-effect bands, exact eligibility, rights, hook/copy/resource limits and failure checks before production; a source-present mechanism is not a satisfied gate.

## Stage Contract

Every stage inspects HEAD/status, applicable AGENTS.md, live producers/consumers/lifetime/build membership and concurrent edits. Apply [Change Integration](../../../../../../../Engineering/Workflow/ChangeIntegration.md), [Change Lifecycle](../../../../../../../Engineering/Workflow/ChangeLifecycle.md), relevant Renderer/RHI/Tools standards and the [Stage Source-Style Gate](../../../../../../../Engineering/Workflow/ChangeLifecycle.md#stage-source-style-gate), including authored readability/spacing review after formatting. Discovery/no-source work records justified source-style N/A.

Ledger every external feature hook and material copy; default to existing semantic inputs, one feature-local owner, zero new public types and no framework. Each stage removes replaced state/paths/selectors/dependencies in the same slice and checks retained consumers. A zero-deletion stage names why no replaced path exists. Temporary probes stay local and are removed before handoff; keep valuable source/commands/results as ignored evidence.

Each exit records exact candidate/dirty state, API/device/tool/content/shader/SDK/artifact identities, command, oracle, observation and remaining cells in `ray-tracing/ptlas/` under the existing workload artifact root. Use the cheapest defect-detecting check; production/native/quality/cost/package/adoption verdicts remain distinct. Stop for missing semantics, required unavailable proof, unsafe lifetime, quality change, silent fallback or a hook outside the frozen budget.
