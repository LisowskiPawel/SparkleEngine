The approved Modern Sponza example excludes Knight. Neither the current release nor the selected classical/neural evidence program needs Alembic playback, a cache codec or another deformation pipeline. The former six-phase implementation sequence and production prompts are retired; they were possible work, not an admitted delivery commitment.

## Admission Decision

Keep the current static/skinned/morph rendering path. Add no Alembic dependency, cooked cache schema, playback/residency API, shader, dormant selector or authoring UI for this deferred capability. Release closeout alone does not change this decision.

Reopen planning only when a named selected workload cannot meet its rendering/evidence goal with the current paths. The scope owner must compare omission/current animation against a bounded cache solution, select the actual source and rights, identify its consumer and measurable benefit, and name the maintenance/deletion cost.

## First Permitted Work If Admitted

Revalidate current ownership and source facts, then resolve only the first selected source-to-consumer slice under the [feature contract](GeometryCacheAnimationDesign.md) and [proof owner](Acceptance.md). They retain constant-topology/vertex identity, coordinate/time/material semantics, bounded range reading, current/previous deformation, raster/ray correspondence, malformed-data refusal and completion-driven retirement. A frozen pose or static fallback cannot prove animation.

Write a new bounded stage sequence from that accepted decision before source work, including the [Stage Source-Style Gate](../../../Engineering/Workflow/ChangeLifecycle.md#stage-source-style-gate) for each admitted slice; no-source work records justified N/A. Each slice must replace its temporary representation in the same change and preserve existing skin/morph consumers. Do not resurrect the former whole roadmap or acquire the Knight archive merely because this page exists.

The [Roadmap](../../../Strategy/Roadmap.md#conditional-and-excluded-work) is the admission/order owner. This deferred page grants no implementation, runtime or release evidence.
